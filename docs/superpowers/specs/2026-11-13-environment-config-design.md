# 环境变量部署

用户已选择直接实施 `.env` / 系统环境变量为主、兼容旧 TOML 的方案，并要求锁屏凭据、无线调试地址/端口和配对码都通过环境配置。

- 配置优先级：系统环境变量 > 项目 `.env` > 可选 `config.toml` > 安全默认值。根目录由入口位置或 `--root` 确定，与下载位置、当前工作目录无关。
- 必填账号和设备连接信息；ADB/Codex 默认从 PATH 查找。连接支持完整 serial 或主机+端口。显式 `pair` 通过标准输入传递临时配对码，`connect` 连接并核对已绑定身份；首次连接可显示设备序列号供填写，绝不自动发布。
- 手机凭据只在 Android 边界读取，不注入模型环境，不输出原始 ADB 错误；旧 PIN/pattern 别名继续有效。读取 `.env` 前要求权限为 0600，不执行插值。
- `enable` / `disable` 的运行开关保存在 `.state`，不再要求改写配置文件，停止仍可取消在途任务。
- 定时任务保留部署时的 PATH、Codex 认证目录、代理及已显式导出的应用配置，文件私有；不保存一次性配对码。研究子进程继续使用严格白名单，排除所有手机配置与凭据。
- README 提供复制 `.env.example`、填写、配对、连接、doctor、启用的完整流程。Python 3.11+、Linux Landlock、ADB、已登录 Codex 为外部前提，不自动安装或更改设备配置。

方案比较：仅系统环境变量不利于终端和定时任务复用；移除 TOML 会破坏已有部署。选择 `.env` 为主并兼容 TOML，保持现有部署和安全边界。

验证：在临时下载目录中仅用 `.env` 或导出变量启动；覆盖优先级、缺失/非法值、绑定身份、配对码标准输入、定时任务持久化/取消、研究环境排除凭据。设备操作仅使用模拟 ADB，不触碰运行中的真机。
