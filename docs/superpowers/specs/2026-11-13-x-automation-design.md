# AI/科技账号自动整理与发布

用户要求：代码独立放于 x-project，使用自己的安卓手机及 X 当前账号，以中文为主每小时 3 条，自动收集 AI/科技新信息，以专业口吻分析，可引用 X、YouTube 视频。密码仅存本机 .env。

采用每小时三个不均匀的随机时刻，时刻写入 SQLite，跨小时也保持至少 8 分钟间隔；启动晚或错过计划不补发。实时网页搜索与结构化生成、来源验证、SQLite 队列和 Android 发布适配分离。手机共享文本 Intent 支持中文与换行，UIAutomator 检查完整文案和账号后点击。默认预览命令；用户已授权的正式定时任务使用 publish。界面测试不发测试帖子。

信息应来自真实、可访问的来源。区分公开发布、原视频简介/标题、实际可读字幕；无字幕不编造看过视频。原创观点与事实分开，不冒充亲测，不搬运视频。模型输出不直接执行命令。只引用已验证 URL，没有新信息时少发。

队列按原文和来源去重，每小时最多三个提交时段，提交后状态不确定则冻结，禁止自动重发。锁屏且有本机数字 PIN 时尝试一次解锁，失败后人工重置；凭据不传给模型。恢复原屏幕开关状态。OPlus 隐藏密码控件时只接受当前系统密码面板的双重显示信号，并要求设备身份绑定。

方案取舍：官方 API 更适合长期无人值守，且 X 规则限制非 API 自动化；本次按用户要求实现手机适配，保留可替换发布接口。无需复制手机登录令牌。源内容和生成任务复用已登录 Codex 的受限 CLI。

限制：手机必须在线且无线 ADB 连接有效；UI 变化应停机而非猜坐标；无密码或图案锁不能无人值守。没有发布回执时不能宣称成功。每小时 3 条是上限，不保证凑足。
