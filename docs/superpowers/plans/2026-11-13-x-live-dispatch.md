# 到点实时采集实施计划

> For agentic workers: use superpowers:executing-plans inline.

**Goal:** 修复真实网页检索能力，每小时3次到点实时采集后发布。
**Architecture:** 研究执行事件核验 → 本时段选中稿 → 新id定向提交；旧队列不参与自动发送。
**Tech Stack:** Python标准库、Codex CLI、Landlock、SQLite、ADB、systemd。
**Spec:** ../specs/2026-11-13-x-live-dispatch-design.md

## Global Constraints
- 凭据不输出；保留Landlock/环境白名单和禁用本地模型工具。
- 实际发送至少间隔8分钟，小时最多3条，未知状态不可重发。
- 未到期不采集；不提前囤稿、不使用旧队列补位、不跨小时补发。

## Review Focus
- 工具路由错误或没有实际搜索不得伪装无新闻。
- 采集耗时超过原120秒仍应允许本窗口发送，超过10分钟/小时边界则停止。
- 新候选失败/重复时旧队列不得被偷偷发出。
- 禁用状态与未知提交不应继续消耗检索。
- 定时任务只取本次id，不可补发其他候选。
